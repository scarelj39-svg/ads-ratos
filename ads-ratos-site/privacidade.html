Política de Privacidade

Ads Ratos · Última atualização: 17 de novembro de 2026

1. Sobre o aplicativo

O Ads Ratos é uma ferramenta de uso pessoal que acessa a Google Ads API para consultar e gerenciar campanhas nas contas Google Ads do próprio titular. Não é oferecido a terceiros.

2. Dados acessados

Mediante autorização OAuth 2.0 concedida pelo titular, o aplicativo acessa dados das contas Google Ads (campanhas, grupos de anúncios, palavras-chave, anúncios, termos de busca e métricas de desempenho) através do escopo https://www.googleapis.com/auth/adwords.

3. Como os dados são usados

Os dados são usados exclusivamente para exibir relatórios e executar alterações solicitadas pelo próprio titular nas suas contas. Não são vendidos, compartilhados com terceiros nem usados para publicidade.

4. Armazenamento

As credenciais de acesso (tokens OAuth) ficam armazenadas apenas localmente, no computador do titular. O aplicativo não mantém servidores próprios nem banco de dados externo.

5. Revogação de acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

6. Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
